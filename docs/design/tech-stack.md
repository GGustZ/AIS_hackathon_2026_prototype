## ส่วนที่ยากที่สุด การอ่าน PDF ภาษาไทย

**ปัญหา** PDF ที่ออกจาก Word ไม่ได้เก็บข้อความเป็น Unicode แต่เก็บเป็นรหัส glyph ของฟอนต์
ทางเดียวที่จะแปลกลับเป็นตัวอักษรได้คือตาราง ToUnicode ของฟอนต์นั้น
ถ้าตารางนั้นไม่ครบ ตัวอักษรจะหายไปอย่างถาวร กู้คืนไม่ได้

**ที่พบจริงในแผนตัวอย่าง** ฟอนต์ในไฟล์ไม่ได้บันทึก ส ว ศ ไว้เลย ทำให้

```
กลุ่มสาระการเรียนรู้วิทยาศาสตร์   ->  กลุ่มาระการเรียนรู้ิทยาาตร์
การสังเคราะห์ด้วยแสง             ->  การังเคราะ์ด้ยแง
```

ข้อความเสียหายราว 21% ตรงกับที่บันทึกไว้ใน README

**สิ่งที่ทำให้ระบบยังทำงานได้** สามอย่าง

**1. ตรวจว่าฟอนต์ทำตัวอักษรใดหาย แล้วตัดตัวอักษรชุดเดียวกันออกจากฝั่งคลังก่อนเทียบ**

ความเสียหายเป็นการ**ลบ**ตัวอักษร ไม่ใช่การเปลี่ยนเป็นตัวอื่น และลบตัวเดิมทั้งไฟล์
ดังนั้นถ้าตัด ส ว ห ออกจากทั้งสองฝั่ง `หน่วยการเรียนรู้` กับ `น่ยการเรียนรู้` จะกลายเป็นสตริงเดียวกัน

การตรวจใช้**อัตราส่วน ไม่ใช่การนับว่ามีหรือไม่มี** เพราะเอกสารหนึ่งฉบับมีหลายฟอนต์
ในแผนตัวอย่าง ห ปรากฏ 8 ครั้งจากตัวอักษรไทยราว 13,600 ตัว ซึ่งคือ 0.06%
ถ้าใช้เกณฑ์ว่าต้องเป็นศูนย์ จะตรวจไม่เจอ และการจับคู่ทั้งหมดจะพัง

**2. ยอมให้รหัสวิชาหายไปจากรหัสตัวชี้วัด**

`ว 1.2 ม.1/6` เมื่อ ว หาย จะเหลือ `1.2 ม.1/6`
ระบบจึงยอมรับรูปแบบที่ไม่มีตัวอักษรวิชานำหน้า **เฉพาะเมื่อ**ตรวจพบว่า ว เป็นตัวที่ฟอนต์ทำหาย
ผลคือสกัด ว 1.2 ม.1/6, ม.1/7 และ ม.1/8 ออกมาได้ถูกต้องครบ

**3. ไม่พึ่งหัวข้อ "กิจกรรมการเรียนรู้"**

แผนจริงหลายฉบับไม่มีหัวข้อนี้ แต่ใช้หมายเลขแทน เช่น `6.1 ขั้นสร้างความสนใจ`
ระบบจึงกวาดหาชื่อขั้นทั้งเอกสารแทนที่จะรอหัวข้อ และอ่านเวลาจากบรรทัดถัดไปได้
เพราะหัวข้อมักตัดบรรทัดกลางวงเล็บ

**เกร็ดที่ต้องรู้ถ้าจะแก้โค้ดนี้ต่อ** สระ ำ ถูกแยกเป็นสองตัวในไฟล์ PDF และครึ่งแรกมักไม่มีในตาราง
`สำรวจ` จึงออกมาเป็น ` ารวจ` ระบบจึงแปลง ำ เป็น า และตัดช่องว่างทิ้งก่อนเทียบเสมอ

## การเทียบข้อความภาษาไทย

ภาษาไทยไม่มีช่องว่างระหว่างคำ การตัดคำจึงต้องใช้ไลบรารี ซึ่งขัดกับข้อกำหนดว่าไม่มี dependency

ระบบจึงใช้ **character n-gram ขนาด 5 ตัว** แทน

```
คลังเขียนว่า   รากดูดอาหารจากดิน
แผนเขียนว่า    รากดูดซึมสารอาหารจากดิน
```

สองประโยคนี้ใช้คำต่างกัน แต่แชร์ n-gram กันเกินครึ่ง ระบบจึงจับได้
นี่คือการเทียบรูปคำ ไม่ใช่การเข้าใจความหมาย และตั้งค่าไว้ค่อนข้างหลวมโดยตั้งใจ
เพราะการพลาดความเข้าใจผิดที่มีอยู่จริง เสียหายมากกว่าการเตือนเกินที่ครูกดปิดได้ในหนึ่งครั้ง

**บทเรียนสำคัญ** ตอนแรกเทียบกับข้อความทั้งขั้น ผลคือทุกความเข้าใจผิดเข้าเกณฑ์หมด
เพราะข้อความยิ่งยาว ยิ่งมี n-gram สั้นๆ ครบโดยบังเอิญ
แก้โดยตัดเป็นประโยคก่อนแล้วค่อยเทียบ ซึ่งได้ผลพลอยได้คือ**ได้ประโยคที่จะยกมาให้ครูดูพอดี**

## การใช้ design system

หน้าตาทั้งหมดมาจาก `docs/design/stitch_multi_page_website_generator`
โดยแปลง token เป็น CSS ที่เขียนเอง ไม่ได้คัดลอกวิธีที่ mockup ใช้

**สามอย่างที่คัดลอกตรงๆ ไม่ได้**

| สิ่งที่ mockup ใช้ | ปัญหา | สิ่งที่ทำแทน |
|---|---|---|
| Tailwind จาก CDN | ถ้าโหลด CDN ไม่ได้ layout พังทั้งหน้า ไม่ใช่แค่ลดรูป ซึ่งขัดกับ NFR-P-04 | เขียน CSS เองจาก token ชุดเดียวกัน |
| Be Vietnam Pro เป็นฟอนต์หัวข้อ | **ฟอนต์นี้ไม่มีตัวอักษรไทย** หัวข้อไทยใน mockup จึงตกไปใช้ฟอนต์อื่นอยู่แล้ว | Be Vietnam Pro สำหรับอักษรละติน แล้วให้ไทยตกไปที่ Noto Sans Thai ซึ่งตรงกับที่ mockup แสดงจริง |

ฟอนต์ยังโหลดจาก Google Fonts อยู่ ต่างจาก Tailwind ตรงที่ฟอนต์**ลดรูปได้อย่างนุ่มนวล**
ถ้าโหลดไม่ได้ ข้อความยังอ่านออกด้วยฟอนต์ในเครื่อง แต่ถ้า Tailwind โหลดไม่ได้ หน้าจอใช้ไม่ได้เลย

**ที่ปรับจาก mockup โดยตั้งใจ**

- mockup แสดงวิธีสอนหน้าละหนึ่งวิธี แต่ FR-D-01 กำหนดว่าแสดงได้ไม่เกิน 3 รายการต่อหน้า
  จึงคงรายการสามข้อไว้ แล้วยกการ์ดแบบละเอียดของ mockup ไปใช้ที่**หน้ารายละเอียด**แทน
- ปุ่มใช้มุมโค้ง 8px ตามที่ DESIGN.md เขียนไว้ ไม่ใช่ปุ่มมนเต็มใบตามภาพ
  เพราะเอกสารระบุเหตุผลไว้ชัดว่าต้องการให้อ่านเป็นเครื่องมือ ไม่ใช่แอป

## วิธีเผยแพร่บน GitHub Pages

1. push โค้ดขึ้น GitHub
2. ไปที่ Settings แล้วเลือก Pages
3. เลือก Source เป็น **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)`
4. รอสักครู่แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/prototype/`

ต้องเลือก root ไม่ใช่ `/docs` เพราะระบบต้องอ่านไฟล์ CSV ใน `data/` ผ่าน `../data/`
ถ้าเสิร์ฟจาก `/docs` โฟลเดอร์ `data/` จะไม่ถูกเผยแพร่ไปด้วย

**รันในเครื่อง**

```
python -m http.server 8765
```

แล้วเปิด `http://localhost:8765/prototype/`

ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิกไฟล์ไม่ได้ เพราะ ES modules และ `fetch`
ถูกปิดเมื่อเปิดด้วย `file://`

**ทดสอบเอนจินกับแผนจริง**

```
node tools/selftest.mjs path/to/plan.pdf
```

## ข้อจำกัดที่ต้องพูดตรงๆ

1. **การระบุว่าเป็นความเข้าใจผิดข้อไหน ยังหยาบ** ระบบหาประโยคที่เข้าข่ายได้จริง
   แต่เมื่อความเข้าใจผิดสองข้อใกล้เคียงกัน คะแนนจะสูสีกันและอาจติดป้ายผิดข้อ
   ประโยคที่ยกมาให้ครูดูถูกต้อง แต่ป้ายกำกับอาจสลับกันได้
