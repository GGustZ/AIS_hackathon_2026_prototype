# ข้อกำหนดของระบบ

สถานะ 14 ส.ค. 2569 เขียนจาก `input-output-spec.md` `database-schema.md` `pa-documents-explained.md` และเดโมปัจจุบันใน `prototype/index.html`

เอกสารนี้เป็นข้อกำหนดสำหรับ**ต้นแบบที่ทำงานได้จริง** ยังไม่ใช่ระบบที่ขึ้น production

---

## 0. เดโมปัจจุบันทำอะไรได้จริงบ้าง

ต้องพูดให้ตรงก่อน เพราะข้อกำหนดทั้งหมดข้างล่างคือระยะห่างจากจุดนี้

| ส่วน | เดโมตอนนี้ | ต้นแบบที่ทำงานได้จริงต้องเป็น |
|---|---|---|
| แผนการสอน | `const P` ค่าคงที่ในไฟล์ | สกัดจากไฟล์ที่ครูอัปโหลดจริง |
| ข้อค้นพบ | `const F` เขียนไว้ล่วงหน้า 3-4 รายการ | คำนวณจากการเทียบ PLAN กับ CURR MISC HIST |
| การตัดสินใจของครู | ตัวแปรในหน่วยความจำ หายเมื่อรีเฟรช | บันทึกลง HIST และมีผลกับครั้งถัดไป |
| ตัวเปรียบเทียบที่ 3 | จำลองด้วยตัวแปร `run>1` | อ่านจาก HIST จริง |
| ไฟล์ออก | ไม่มี | .docx ที่เปิดใน Word ได้ |

เดโมพิสูจน์ว่า**หน้าตาและลำดับหน้าจอใช้ได้** ยังไม่ได้พิสูจน์ว่าระบบทำงานได้

## 1. ขอบเขต

**อยู่ในต้นแบบนี้**

ทางเข้าแบบมีแผนอยู่แล้ว ตัวเปรียบเทียบ 3 ตัว การตัดสินใจของครู แผนฉบับปรับแล้ว ชุดข้อวัด หลักฐาน ว.PA คลังอ้างอิงที่ seed ไว้ และการแนบ Learning Evidence แบบไม่บังคับเพื่อเก็บและจัดประเภทกับแผน

**ไม่อยู่ในต้นแบบนี้ วาดไว้ในไดอะแกรมแต่ติดป้ายว่ายังไม่สร้าง**

การวินิจฉัยอัตโนมัติจากภาพงานนักเรียน รายชื่อนักเรียน การวัดผลก่อนและหลัง การเทียบข้ามครู การรวมระดับเขตหรือระดับชาติ

**ผู้ใช้**

| รหัส | ใคร | ทำอะไร |
|---|---|---|
| U1 | ครูผู้สอน | ผู้ใช้หลักเพียงคนเดียวในเฟส 1 |
| U2 | ผู้ดูแลคลัง | เขียนและรับรอง MISC METHOD ITEM EVID ไม่ใช่ผู้ใช้ในระบบเดียวกัน |

ไม่มีบทบาทผู้อำนวยการ ไม่มีบทบาทเขตพื้นที่ ในเฟส 1 การเพิ่มบทบาทเหล่านี้จะทำให้ระบบกลายเป็นเครื่องมือกำกับติดตาม ซึ่งเปลี่ยนแรงจูงใจของครูจากผู้ใช้เป็นผู้ถูกตรวจ

**ระดับความสำคัญ**

| ระดับ | ความหมาย |
|---|---|
| P0 | ไม่มีแล้วเดโมเล่าเรื่องไม่จบ |
| P1 | ต้องมีก่อนให้ครูจริงใช้ |
| P2 | เฟส 2 |

## 5. สิ่งที่ยังเขียนเป็นข้อกำหนดไม่ได้

เขียนไว้ตรงนี้แทนที่จะเดาตัวเลขลงไปในตารางข้างบน

1. **เกณฑ์ความมั่นใจใน FR-A-06** ยังไม่มีตัวเลข ต้องรันการสกัดกับแผนจริงหลายฉบับก่อนจึงจะรู้ว่าเส้นควรอยู่ตรงไหน
2. **จำนวนครั้งของการปฏิเสธใน FR-K-03** ที่ทำให้ระบบเลิกเสนอวิธีที่ต้องใช้อุปกรณ์ ยังไม่มีฐานให้ตั้ง
3. **ขนาดคลังขั้นต่ำ** ที่ทำให้ระบบมีประโยชน์กับแผนที่ครูอัปโหลดมาแบบสุ่ม ตอนนี้คลังครอบ 1 ตัวชี้วัด ถ้าครูอัปโหลดเรื่องอื่นระบบจะตอบ FR-L-02 ได้อย่างซื่อสัตย์แต่ไม่มีประโยชน์
4. **จำนวนส่วนของ ว.PA ที่เคลมได้** ยังไม่ตรงกันระหว่าง README กับสเปก เลื่อนการตัดสินใจไว้แล้ว
