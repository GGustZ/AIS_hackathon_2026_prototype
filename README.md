# ตรวจรู้ (TruatRoo)

**ผู้ช่วยตรวจแผนการสอนสำหรับครูวิทยาศาสตร์**
AIS JumpThailand Hackathon 2026 · แทร็ก Empowering Teachers

> ครูเอาแผนการสอนที่เขียนไว้แล้วมาให้ระบบดู ระบบบอกว่าแผนยังขาดอะไร แล้วเสนอสิ่งที่เติมได้ พร้อมเหตุผล
>
> **ระบบไม่ได้เขียนแผนแทนครู** สิ่งที่ลดคือเวลาที่ครูต้องไปค้นเองว่าเด็กมักติดตรงไหน และวิธีไหนใช้ได้

ครูที่ยังไม่มีแผน เริ่มจากการเลือกเนื้อหาและปัญหาที่เจอได้ ไม่ต้องมีไฟล์ก่อน

## ลองใช้

**ออนไลน์** เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/prototype/`
(ตั้งค่าที่ Settings > Pages > Deploy from a branch > main > `/ (root)`)

**ในเครื่อง** รัน `python -m http.server 8765` ที่โฟลเดอร์รากของโปรเจกต์
แล้วเปิด `http://localhost:8765/prototype/`
ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิกไฟล์ไม่ได้ เพราะระบบต้องโหลดคลัง CSV ตอนรัน

ระบบ**อ่านไฟล์แผนจริงที่คุณอัปโหลด** ทั้ง .docx และ .pdf ประมวลผลในเบราว์เซอร์เครื่องคุณเท่านั้น
ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งไฟล์ออกไปที่ใด

[`prototype/mock.html`](prototype/mock.html) คือเดโมหน้าตาเดิมที่ใช้ข้อมูลสมมติ เก็บไว้เทียบเท่านั้น

**สามทางเข้า**

| ทางเข้า | เหมาะกับใคร | ได้อะไร |
|---|---|---|
| มีแผนการสอนแล้ว | ครูที่เขียนแผนไว้แล้ว | อัปโหลด .docx หรือ .pdf แล้วได้ diff ว่าแผนขาดอะไร |
| ยังไม่มีแผนการสอน | ครูที่เพิ่งเริ่ม | เลือกชั้น รายวิชา บทเรียน แล้วได้ความเข้าใจผิดของหน่วยนั้น |
| มีปัญหาผู้เรียน | ครูที่รู้ว่าเด็กติดตรงไหน | เลือก Bloom DOK PISA และปัญหา 26 ข้อ แล้วได้วิธีสอนที่ตรงกับปัญหา |

ทุกทางแสดงความเข้าใจผิดของหน่วยนั้น**ไว้บนสุด**เสมอ ถ้าวางไว้ท้าย ครูจะอ่านแล้วปิด

**ยังไม่มีไฟล์ก็ลองได้** ปุ่ม "ลองด้วยแผนตัวอย่าง" ในการ์ดแรกจะโหลด
[`prototype/sample-plan.docx`](prototype/sample-plan.docx) ซึ่งเป็นแผนสมมติที่สร้างด้วย
`tools/make-sample.mjs` ชื่อโรงเรียนและชื่อครูเป็นชื่อสมมติทั้งหมด
แผนนี้จงใจใส่ข้อความที่ไปเสริมความเข้าใจผิดไว้ เพื่อให้เห็นว่าระบบจับได้จริง

หน้าตาใช้ design system จาก `docs/design/stitch_multi_page_website_generator`
แปลง token เป็น CSS ที่เขียนเอง ไม่ได้ใช้ Tailwind จาก CDN ตามที่ mockup ทำ
เพราะถ้าโหลด CDN ไม่ได้ layout จะพังทั้งหน้า ไม่ใช่แค่ลดรูป

**มุมมองเทคนิค** ไม่มีปุ่มบนหน้าจอ ต่อท้าย URL ด้วย `#tech` เพื่อดูว่าคำแนะนำแต่ละข้อมาจากตารางไหนและกฎอะไร
ตั้งใจไม่ให้เป็นปุ่ม เพราะมีไว้ตอบกรรมการ ไม่ได้มีไว้ให้ครูที่กำลังใช้งาน

ตัวอย่างที่ใช้เป็นแผนจริงระดับ ม.1 เรื่องการสังเคราะห์ด้วยแสง ตัวชี้วัด ว 1.2 ม.1/6-8 โครงสร้าง 5E

## สิ่งที่พบจากการทดสอบกับแผนจริง

**1. ไฟล์ PDF ของแผนจริงสกัดข้อความออกมาไม่ครบ**

แผนตัวอย่างฝังฟอนต์แบบที่ทำให้ **ตัวอักษร ส ห ว ศ หายไปทั้งไฟล์** คำว่า "สังเคราะห์ด้วยแสง" อ่านออกมาเป็น "การังเคราะ์ด้ยแง" ตัวสกัดปัจจุบันวัดความเสียหายได้ 20.7%

**แต่โครงสร้างยังสกัดได้** หัวข้อที่มีเลขกำกับและรหัสตัวชี้วัดอ่านได้ครบ ทดสอบแล้วดึง ว 1.2 ม.1/6, ม.1/7, ม.1/8 ออกมาถูกต้อง

สรุป **โครงสร้างรอด เนื้อหาไม่รอด** ระบบจึงยังรู้ว่าแผนผูกกับตัวชี้วัดไหน ซึ่งเป็นสิ่งที่จำเป็นที่สุด ส่วนฟิลด์ที่เสียให้ตกไปที่ OCR หน้ากระดาษ (ข้อความพิมพ์ ไม่ใช่ลายมือ ความแม่นยำสูงกว่ามาก) แล้วให้ครูยืนยัน

นี่คือเหตุผลที่ระบบแสดงความมั่นใจรายฟิลด์ ไม่ใช่รายไฟล์

**2. ระบบทำงานได้ทั้งที่ไฟล์เสียหาย**

เพราะความเสียหายเป็นการ**ลบ**ตัวอักษร ไม่ใช่เปลี่ยนเป็นตัวอื่น และลบตัวเดิมทั้งไฟล์
ระบบจึงตรวจว่าฟอนต์ทำตัวใดหาย แล้วตัดตัวชุดเดียวกันออกจากฝั่งคลังก่อนเทียบ
`หน่วยการเรียนรู้` กับ `น่ยการเรียนรู้` จึงกลายเป็นสตริงเดียวกัน รายละเอียดอยู่ใน `docs/design/tech-stack.md`

**3. คำแนะนำในเดโมมาจากเนื้อหาจริงในแผน ไม่ได้แต่งขึ้น**

- เฉลยคำถามนำข้อ 2 เขียนว่ารากดูดซึม "สารอาหาร" จากดิน ซึ่งไปเสริมความเข้าใจผิดที่พบบ่อยที่สุดของเรื่องนี้
- เฉลยเกมข้อ 10 เขียนว่ากลางคืน "มีแต่การหายใจเท่านั้น" ซึ่งเด็กมักอ่านต่อเองว่ากลางวันพืชไม่หายใจ
- สามขั้นสุดท้ายของ 5E ไม่ได้ระบุเวลา ในคาบ 50 นาทีที่เหลืออยู่ 25 นาที

## ข้อจำกัดที่ระบุไว้ตรงไปตรงมา

- ระบบช่วย ว.PA ได้ 6 จาก 9 ส่วน ส่วนที่ต้องมีผลการวัดจริงยังทำไม่ได้
- คลังความเข้าใจผิดมี 6 รายการ ครอบ 1 ตัวชี้วัด ยังไม่ใช่ทั้งหลักสูตร
- วิธีสอนที่ผูกกับความเข้าใจผิดแล้วมี 20 จาก 110 รายการ ที่เหลือยังเป็นคลังตั้งต้นที่ยังเลือกอัตโนมัติไม่ได้
- ทุกแถวใน `DB4_methods_bound_draft.csv` ยังเป็น `draft` เพราะยังไม่มีการอ้างอิงงานวิจัยรายรายการ ช่อง `evidence_note` เขียนข้อจำกัดไว้ตรงๆ ทุกแถว
- เดโมใช้ไฟล์ตัวอย่างที่เตรียมไว้ ยังไม่รองรับแผนทุกรูปแบบ
- ตัวเลขคะแนน PISA ที่อ้างในเอกสารเป็นความสัมพันธ์ ไม่ใช่เหตุและผล
- ยังไม่ได้สัมภาษณ์ครูจริง หลักฐานทั้งหมดเป็นข้อมูลทุติยภูมิ

## หมายเหตุเรื่องข้อมูลส่วนบุคคล

`data/samples/` **ไม่ได้ commit ขึ้นคลังนี้** เพราะแผนตัวอย่างมีชื่อโรงเรียน ชื่อครูผู้สอน และห้องเรียนจริง ซึ่งเจ้าของยังไม่ได้ให้ความยินยอมเผยแพร่ ไฟล์ถูกใส่ไว้ใน `.gitignore` แล้ว

ถ้าจะเผยแพร่คลังนี้แบบสาธารณะ ให้ตรวจก่อนว่าไม่มีไฟล์ในโฟลเดอร์นั้นหลุดเข้า commit
